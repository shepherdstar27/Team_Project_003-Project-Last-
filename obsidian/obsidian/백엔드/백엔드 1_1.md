데이터의 물리구조가 응용프로그램 곳곳에 하드코딩 되어 있었으니 유지보수성 문제
프로그램과 데이터가 한몸이라 데이터 종속성 문제 (데이터를 바꾸려면코드를 바꿔야 함)

기존의 문제점
데이터 종속성 - 각 프로그램마다 독자적인 파일
데이터 호환성과 표준화 - 자료형이 일치하지 않을 수 있음
데이터 중복성 - 파일이 각각만들어져 동일한 내용 중복
데이터 무결성 침해 - 본래 의도와 다른 형식과 범위
데이터 불일치 - 별개의 파일이다보니 서로 저장된 정보가 달라짐
데이터 보안성 결여 - DB는 각 테이블에 대한 접근권한 다름



위 파일 시스템의 한계를 극복하기위해 테이블 형태의 관계형 데이터 베이스가 나왔음
응용프로그램 <->데이터 사이에 데이터 베이스 매니징 시스템이라는 DBMS를 두어 서로의 변경여파 차단

각 프로그램 <-> DBMS <-> OS <-> 데이터 베이스

관계중심 이라는 용어가 중요.

데이터 베이스에는 DBMS를 통해서만 접근(중앙집권)
데이터 독립성 보장
데이터 무결성 위반 차단
사용자에 따른 데이터 접근 제한(높은 데이터 보안성)

DBMS(데이터 베이스 매니징 시스템이라고 함)
데이터 본부 처리 시스텀, 데이터 베이스에 실질적인 데이터를 조회, 추가, 제거, 삭제, 변경을 수행

위 DBMS와 반대 되는 개념이 블록체인 등장
