SQL이란

DDL(데이터 정의어)
create 데이터 베이스, 테이블, 인덱스 등 기본 구조 생성
alter 이미 존재하는 테이블의 구조(컬럼추가, 타입 변경)을 수정
drop 테이블이나 데이터베이스 삭제
truncate테이블 구조 남겨두고 데이터만 전부 초기화

create
● 다만, 데이터 정의어에서 Create 말고는 사실 쓸 일이 없는게 건강한 시스템이다!
● Alter : 구조변경
○ 이미 서비스 중인 상태에서 테이블 구조를 바꾸는 건 아주 아주 아주 위험한 작업임
○ 기획 단계에서 DB 스키마를 탄탄하게 완료하고, 서비스 런칭 후에는 컬럼 자체를 변경할 일이
없는게 맞음
● Drop : 삭제
○ 실험 단계에선 종종 쓰더라도, 라이브 중에는 엄격하게 권한 제한을 둬 Drop을 절대 할 수 없도록 함
○ Table을 안쓰게 되는 경우에도 제거하는 것이 아니라, 차라리 테이블 이름을 _deleted나 _old 같은
이름으로 변경하거나 컬럼을 추가해 isDeleted를 true, false
○ 또한 제거 전 스냅샷(백엄) 필수로 떠둠
● Truncate : ..넘어가자 (DB는 통째로 날릴만한 상황 자체가 있으면 안된다)



DML (Data Manipulation Language) / 데이터 조작어

● 완전 많이 씁니다. 실질적인 DB의 데이터 관리 핵심 조작어입니다.
● SELECT : (조회 - Read)
○ 테이블에 저장된 데이터를 가져옴
○ ex) SELECT * FROM users WHERE level > 10; (레벨이 10보다 큰 유저 조회)
● INSERT : (입력 - Create)
○ 테이블에 새로운 데이터 추가
○ ex) INSERT INTO users (name, level) VALUES (‘daniel’, 100);
● UPDATE : (수정 - Update)
○ 이미 존재하는 데이터의 내용을 변경
○ ex) UPDATE users SET level = 2 WHERE name = ‘daniel’;
● DELETE : (삭제 - Delete)
○ 테이블에 있는 특정 데이터 삭제
○ ex) DELETE FROM users WHERE name = ‘daniel’;
